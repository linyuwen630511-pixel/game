🏆 課堂 PK 排行榜

排名：總分 → 整體正確率 → 誤報率（低者優先）→ 平均反應時間（短者優先）

📖 遊戲規則

  1. 畫面一次只出現一個刺激（位置、符號，或兩者同時）。
  2. 判斷目前刺激是否與往前數第 N 個刺激相同。2-back 比的是「前前一個」，不是上一個。
  3. 前 N 個刺激是暖身（顯示「記憶準備中」），不用作答、不計分。
  4. 從刺激出現到下一個刺激出現前，按「相同」或「不同」；每個試次只接受第一次作答，沒按就算未作答。
  5. 雙重 N-back：位置與符號各自獨立判斷、各自計分。

2-back 範例：A → B → A（相同） → C（不同） → B（不同）

計分與指標

  • 答對 +10；答錯、未作答 0 分；每連續答對 5 次另加 20 分（5、10、15…各一次）。
  • 整體正確率＝正確數 ÷ 可判定試次數（未作答算在分母）。
  • Match 命中率＝答對的 Match ÷ 實際 Match 數；誤報率＝把 Non-match 判成「相同」÷ 實際 Non-match 數。
  • d′（敏感度）與 c（反應偏向）使用 log-linear 修正（命中與誤報各加 0.5、分母加 1），避免 0% 或 100% 時出現無限值。
  • 平均反應時間只計算有作答的試次。

七種預設難度

自動闖關晉級條件

整體正確率 ≥ 80%、Match 命中率 ≥ 70%、誤報率 ≤ 30%，三項都達標才能晉級（每關 20 次刺激、Match 比例 30%）。

🧠 工作記憶小教室

1. 工作記憶（Working Memory）

短時間「維持並操作」資訊的心智工作區。例：一邊聽老師報作業頁碼，一邊翻到那一頁。

2. 工作記憶更新（Updating）

不斷放入新資訊、丟掉過時資訊。N-back 每出現一個新刺激，就要把「要比較的那一個」往後挪一格。

3. 持續性注意力（Sustained Attention）

在一長串刺激中維持專注；一恍神就會錯過或比錯對象。

4. 認知控制（Cognitive Control）

依照規則選擇反應、抑制衝動。例：看到和「上一個」一樣時，忍住不按「相同」，因為規則是比「前 2 個」。

5. N-back 任務

  • 1-back：和上一個比較，只需記住 1 個。
  • 2-back：和前前一個比較，要同時記住並更新 2 個。
  • 3-back：要記住 3 個且不斷輪替，負荷明顯增加。

6. Lure 干擾試次

例如 2-back 中，目前刺激與「前 1 個」或「前 3 個」相同，卻與「前 2 個」不同——正確答案仍是「不同」。Lure 會誘發「好像看過」的熟悉感，考驗你是否真的記得位置順序，而不只是「有沒有出現過」。

7. 工作記憶與兒童發展

工作記憶在兒童期到青少年期逐漸成熟，與閱讀理解、心算、遵循多步驟指令與問題解決等學習活動有關。學齡期兒童一次能維持與操作的資訊量較成人少，因此教學時可將步驟拆小、提供視覺提示。

本遊戲僅作為教育體驗活動，不是標準化認知測驗。成績可能受練習、刺激速度、策略、注意力及反應方式影響，不能以單次遊戲成績推論個人智力或診斷認知障礙。
